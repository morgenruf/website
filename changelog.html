Changelog

New features, improvements, and fixes for Morgenruf.

v1.0.0
April 5, 2026

Features

  • Configurable standup schedule per team (times, timezones, days)
  • DM-based collection — bot DMs each member individually
  • Custom questions — fully editable from the dashboard
  • Skip today — DM skip to opt out for the day
  • Pre-standup reminder — configurable minutes before standup time
  • Per-user timezone — DM timezone America/New_York to set personal timezone
  • Blocker detection — highlights blockers in summaries
  • Manual trigger — type standup in DM anytime
  • Mood tracking — 4th question captures team sentiment
  • Auto-linking — Jira/GitHub/Linear issue references become clickable
  • Webhooks — HMAC-signed HTTP webhooks on standup.completed
  • Edit window — members can edit responses within configurable time
  • Web dashboard with analytics
  • Participation analytics with 7d/30d views
  • CSV export
  • Weekly digest email to admins
  • Welcome email for new workspaces
  • Multi-workspace Slack OAuth
  • Role-based access control (admin/member)
  • 25 pre-built question templates
  • Kudos/peer recognition system
  • Workflow automation rules
  • Optional AI summaries (OpenAI/Anthropic)
  • MCP server integration
  • Google Chat adapter (Beta)
  • Docker, Helm, and AWS CloudFormation deployment
