Deployment

Three ways to deploy

Pick the method that fits your infrastructure. All production-ready.

🐳

Docker Compose

The simplest path. Clone, configure, and docker compose up -d. Runs on any machine with Docker.

~$5/mo on a VPS
☸️

Kubernetes / Helm

Production Helm chart with support for external PostgreSQL, Cloudflare Tunnel, and horizontal scaling.

Your existing cluster
☁️

AWS CloudFormation

One-click AWS deployment. Starter template (EC2) or production template (ECS Fargate + RDS + ALB).

~$15–$25/mo on AWS
Security & Privacy

Why self-hosting your standup bot matters

Standup responses contain sensitive project details, timelines, and team health data.

🏠

Complete data ownership

Every standup response, mood check-in, and analytics data point lives in your PostgreSQL database. No vendor has access.

🛡️

Zero telemetry

Morgenruf sends absolutely no data back to us. No analytics, no usage tracking, no phone-home. Verify it in the open-source code.

🔑

Your encryption keys

Configure your own secrets, TLS certificates, and database encryption. You control the entire security posture.

📋

Compliance friendly

Self-hosting means you decide where data is stored geographically. Meet GDPR, SOC 2, HIPAA, or internal compliance requirements.

🔍

Fully auditable

MIT-licensed open source. Your security team can audit every line of code before deployment.

🔒

Network isolation

Run Morgenruf inside your VPC or private network. Use Cloudflare Tunnel to avoid exposing ingress endpoints.
