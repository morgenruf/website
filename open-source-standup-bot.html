Why Open Source

Why teams choose open-source standup tools

Closed-source SaaS standup bots come with trade-offs. Open source eliminates them.

🔍

Full transparency

Every line of code is public. Audit what touches your Slack workspace. No black boxes, no trust-us-bro security.

🔧

Fork & customize

Need a custom question type or integration? Fork the repo and build it. MIT license means no restrictions.

🔒

Data sovereignty

Standup responses can contain sensitive project details. Self-hosting means that data never leaves your infrastructure.

🚫

No vendor lock-in

SaaS tools can raise prices, sunset features, or shut down. Open source means you're never at the mercy of a vendor.

🤝

Community-driven

Features are driven by real team needs, not sales targets. Contribute code, open issues, vote on the roadmap.

💰

Zero cost

No per-user pricing. No tiers. No credit card. The only cost is your server — as low as $5/month.

Get Started

Deploy in minutes

Choose your deployment method. All paths lead to a fully working standup bot.

# Docker Compose (simplest)
git clone https://github.com/morgenruf/morgenruf.git
cd morgenruf
docker compose up -d

# Kubernetes via Helm
helm repo add morgenruf https://charts.morgenruf.dev
helm install morgenruf morgenruf/morgenruf

# AWS CloudFormation
# Templates provided for EC2 (~$15/mo) and ECS Fargate (~$25/mo)
Features

Production-grade features, zero cost

Everything you'd expect from a paid standup tool — and more.

🎯

Custom questions

25 pre-built templates or write your own. Ask exactly what your team needs to share.

⏰

Smart scheduling

Timezone-aware with per-user timezone overrides. Respects weekends and working hours.

📊

Analytics & export

7-day and 30-day participation rates, blocker tracking, and one-click CSV export.

🎭

Mood tracking

Built-in team health monitoring with emoji mood check-ins after every standup.

🔔

Webhooks

HMAC-signed webhooks push standup data to any endpoint for custom integrations.

🤖

MCP / AI ready

Built-in MCP server for Claude, Cursor, and GitHub Copilot integration.
